## Task Observer Activation (MANDATORY)

Before using ANY tool in a new task session, load the task-observer skill
first. This is not optional — it is a session-start requirement. If you are
about to call a tool and have not yet loaded task-observer, stop and load it.
The task-observer runs silently in the background, capturing patterns worth
preserving as reusable skills.

When loading any skill, check the observation log for OPEN observations
tagged to that skill. Apply their insights to the current work, even if
the skill file hasn't been updated yet. This enables immediate application
of observations before they're permanently integrated during the weekly
review.

## Observation Storage

- Log: `~/.local/share/task-observer/skill-observations/log.md`
- Principles: `~/.local/share/task-observer/skill-observations/cross-cutting-principles.md`
- Staged updates: `~/.local/share/task-observer/skill-updates/`

## Weekly Review Cadence

The task-observer recommends running comprehensive skill reviews on a
cadence of Monday/Wednesday/Friday mornings. This ensures observations
are regularly processed and skills stay current.
