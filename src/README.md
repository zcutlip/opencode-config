`~/.config/opencode` again via `install.sh` — but only after the Phase 5
checkpoint (diff and fold any hand-built config out of the live directory
first). Until then, config is built here gradually as items prove load-bearing
under vanilla V2. See `../archive/README.md` — the port ledger — before
pulling anything out of the archive.
