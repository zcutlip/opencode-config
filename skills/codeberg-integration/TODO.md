## Notes

- **AI Disclosure Requirement**: All write operations MUST automatically prefix body text with `[Generated by AI]` before sending to the API. This should be enforced at the client level, not left to callers.
- **API Version**: Currently targeting Forgejo API (compatible with Codeberg.org)
- **Authentication**: Uses `CODEBERG_TOKEN` environment variable
- **Safety**: Consider adding dry-run mode or confirmation prompts for destructive operations
